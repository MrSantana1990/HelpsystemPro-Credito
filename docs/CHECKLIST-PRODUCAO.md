# Checklist de Produção

## O usuário precisa liberar

- [ ] domínio ou subdomínio;
- [ ] acesso ao DNS;
- [ ] servidor Linux ou conta no provedor escolhido;
- [ ] acesso SSH administrativo temporário;
- [ ] endereço de e-mail operacional;
- [ ] política de quem pode acessar o sistema;
- [ ] decisão sobre retenção de dados e backups;
- [ ] validação jurídica dos contratos, juros, multa e cobrança;
- [ ] confirmação do nome do cliente associado à planilha atual.

## Para integrações futuras

- [ ] conta WhatsApp Business/API oficial;
- [ ] provedor de e-mail transacional;
- [ ] PSP ou banco autorizado com API Pix;
- [ ] fornecedor de assinatura eletrônica;
- [ ] parceiro autorizado para análise de crédito;
- [ ] seguradora ou corretora habilitada.

## Verificação técnica

- [ ] GitHub Actions aprovado;
- [ ] `npm audit` sem vulnerabilidades;
- [ ] build de produção aprovado;
- [ ] testes unitários e de integração aprovados;
- [ ] HTTPS válido;
- [ ] cookie seguro ativo;
- [ ] porta interna fechada para a internet;
- [ ] backup automático fora do servidor;
- [ ] restauração testada;
- [ ] monitoramento e alerta de indisponibilidade;
- [ ] importação revisada;
- [ ] totais comparados com a planilha;
